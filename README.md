## The entry

One letter: **C** — C for *chaotic*.

The judge infers the word behind the letter. "Chaotic" paints a sharp, specific picture of a day spiralling out of control: vivid, funny, and an honest report of a real day. The hard C suits the word's punch. It is deliberately not one of the rules' own example letters (A, F, Z), which the house fixed texts most likely use.

## How it works

`main.ts` writes the single character `C` to `/output/entry.txt` (via `MAKEFUN_OUTPUT_DIR`, defaulting to `out`), with no newline and nothing else — exactly 1 character, inside the gate.

Run it:

```sh
node main.ts
```
